# Todo App 📝

A simple and lightweight Todo application built to help you manage your daily tasks efficiently.

## Features ✨
* Add new tasks easily
* View your task list
* Clean and responsive design

## Tech Stack 🛠️
* *Backend:* Python, Flask
* *Database:* SQLite (todos.db, tasks.db)
* *Frontend:* HTML, CSS
